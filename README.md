# Dogfile updates

This repository hosts the releases of Dogfile, the file manager for Windows.
Installed copies of Dogfile read `latest.json` from the newest release here and offer the update.

Each release holds:
- `Dogfile-<version>-setup.exe` — the installer for new users
- `Dogfile-<version>-app.zip` — the program (Dogfile.exe) for the auto-updater; `-arm64-app.zip` for Windows on ARM
- `latest.json` — the version, date, changes and the files to download, with SHA-256 checksums
